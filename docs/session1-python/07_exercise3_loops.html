Exercise 3 — Loops
Avoid writing many lines of code by writing your own for loops and while loops.

Same drill as Exercise 2: try first, Hint when stuck. Work in the same .py file, with # Exercise 3 comments to keep it navigable.

Part 1: Basic for loops

Make a list where each item is one of the five basic senses (hearing, seeing, etc.) as a character string.

Then use a for loop to iterate over all 5 senses and print their names.

Bonus:

Use a formatted string expression to print:

“One of the five human senses is {sense}” on each iteration of the loop (where sense is updated on each iteration of the loop).

Hint

Keep it simple, this is the most basic type of for loop. For formatted strings, remember the module on printing variable expressions.

Part 2: Using counter variables in for loops

  1. Define a counter variable sense_number
  2. Rewrite the for loop from Part 1, but add 1 to sense_number on each iteration of the loop.
  3. Add a print expression to the loop that prints a sentence containing the value of sense_number and sense on each iteration.
Hint

Be mindful of where you place the counter variable: Should it come before or after the print() statement?

🔒 Example code will be available here after the workshop

Part 3: For loops by list indexing

We can also iterate loops using indexing.

  1. Make a new list variable numeric_order, this time containing the words “first”, “second”, “third”, “fourth”, etc. through “tenth”. So, there should be 10 items in this list.
  2. Write code to return the total number of items in numeric_order and store this value in a variable called len_order.
  3. Use range() to generate a range of values from 0 up to but not including len_order. Store this range of values in a variable called order_range
  4. Write a for loop that iterates over order_range, indexes each item of numeric_order using the current iteration number and prints it.
Hint

Remember to use the index to the current loop iteration to get the current value of numeric_order.

🔒 Example code will be available here after the workshop

Part 4: While loops

Okay, now an exercise for our last type of loop, the while loop.

  1. Create a counter variable that is initialized with a value of 0.
  2. Write a loop that iteratively increases the counter by 2 while the counter is less than 30.
  3. On each iteration of the loop print “I am current age, not yet 30”, where current_age is the value of the counter.
Hint

The operator for less than is <, we will learn more about comparison operators in the next section.

  1. Make a list of fruits.
  2. Iterate over this list in a for loop.
  3. Make a for loop inside of this outer loop that iterates over each character in the current item and prints it separately!

The outer loop gives you one fruit at a time. Put an inner loop inside it to iterate over the characters in that fruit.
