Put the CogWheel stimulus images in this folder.

Expected naming convention (the code depends on it):
  stimulus1_L.jpg   -> correct response: LEFT arrow
  stimulus2_R.jpg   -> correct response: RIGHT arrow
  ...

Also place the two feedback images one level up, next to the scripts:
  success.jpg
  failure.jpg

(Optional, for the advanced sound task: correct.wav next to the scripts.)
