# Python × PsychoPy Workshop

Course Quarto website for the three-session Python/PsychoPy workshop
(**Methods 01 × Cognition & Communication**). 

**The arc:** Session 1 builds the Python foundations → Session 2 turns them into a
PsychoPy experiment → Session 3 adds timing and logging, ending in the self-paced
reading prototype for Portfolio 2.

 Session | Folder | Status |
|---|---|---|
| 1 · Python basics (on UCloud) | `session1-python/` | 🚧 outlined |
| 2 · Introduction to PsychoPy | `session2-psychopy/` | ✅ drafted |
| 3 · Timing, data & the reading experiment | *(planned)* | 📋 outlined |


## Repo structure

```
_quarto.yml              site config: navbar, sidebar, theme. New chapters are registered here.
index.qmd                workshop landing page

session1-python/         Session 1 chapters
  index.qmd                day overview: learning outcomes, programme
  01_getting_started.qmd   first chapter
session2-psychopy/       Session 2: day overview + 11 chapters
materials/               setup_check.py + stimuli/ (real images added before the day)
docs/                    RENDERED SITE: generated by `quarto render`; never edit by hand
```
